# SEO — как люди найдут твоё портфолио в Google

Эта инструкция — что **уже сделано** (технически) и что **тебе нужно сделать вручную**, чтобы сайт появился в поиске.

---

## ✅ Что уже сделано (автоматически)

| Файл | Что делает |
|------|-----------|
| `public/robots.txt` | Разрешает Google и Yandex индексировать сайт |
| `public/sitemap.xml` | Карта сайта — говорит поисковику, какие страницы есть |
| `public/og-image.svg` | Картинка-превью для Telegram, Facebook, LinkedIn, VK |
| `index.html` мета-теги | `description`, `keywords`, `canonical`, `robots` |
| `index.html` Open Graph | Превью при шаринге ссылки в соцсетях |
| `index.html` JSON-LD | Структурированные данные `Person` — Google понимает, кто ты |
| `index.html` Twitter Card | Превью в Twitter/X |

После `git push` Vercel пересоберёт сайт за ~10 секунд, и всё это станет доступно.

## ❌ Что нужно сделать ТЕБЕ вручную (5 шагов, ~30 минут)

### Шаг 1. Купи свой домен (важно для SEO)

Vercel-поддомен `github-portfolio-delta-ruby.vercel.app` Google индексирует, но он **не ранжируется хорошо** — слишком много шума в поддомене. Свой домен (`viacheslav.dev`, `biezhanov.com` и т.д.) поднимает позиции в поиске в 5–10 раз.

Где купить:
- **Namecheap** — https://namecheap.com (от $8/год за `.dev`, `.com`)
- **Porkbun** — https://porkbun.com (часто дешевле)
- **Cloudflare Registrar** — https://cloudflare.com (без наценки)

Подключить к Vercel:
```bash
vercel domains add viacheslav.dev
# Затем в дашборде Vercel добавь DNS-записи, которые покажет Vercel.
```

После этого **обнови URL** в файлах:
- `index.html` — `canonical`, `og:url`, `og:image`, JSON-LD `url`/`image`
- `public/robots.txt` — `Sitemap: https://viacheslav.dev/sitemap.xml`
- `public/sitemap.xml` — все `<loc>` на новый домен

### Шаг 2. Добавь сайт в Google Search Console

1. Открой https://search.google.com/search-console
2. Войди через Google-аккаунт
3. Нажми «Add property» → «URL prefix» → вставь свой URL
4. Подтверди владение (3 способа):
   - **HTML tag** — добавь мета-тег в `<head>` `index.html` (проще всего)
   - **DNS TXT record** — добавь через регистратора домена
   - **HTML file** — положи файл в `public/`
5. После подтверждения: **Sitemaps** → добавь `https://viacheslav.dev/sitemap.xml`
6. Жди 2–7 дней — Google проиндексирует и страницы появятся в поиске

### Шаг 3. Добавь в Yandex Webmaster (для русскоязычной аудитории)

1. Открой https://webmaster.yandex.ru
2. Войди через Яндекс или Google-аккаунт
3. «Добавить сайт» → вставь URL
4. Подтверди владение (аналогично Google)
5. Раздел «Индексирование» → «Файлы sitemap» → добавь `https://viacheslav.dev/sitemap.xml`
6. Жди 1–14 дней

### Шаг 4. Добавь в Bing Webmaster Tools (для Bing, Yahoo, DuckDuckGo)

1. Открой https://www.bing.com/webmasters
2. Войди через Microsoft или Google-аккаунт
3. Add site → вставь URL → подтверди владение
4. Submit sitemap

### Шаг 5. Запроси индексацию вручную (быстрый старт)

После подтверждения в Google Search Console:
1. Открой «URL Inspection»
2. Вставь свой URL
3. Нажми «Request indexing»
4. То же самое в Yandex: «Индексирование» → «Переобход страниц»

Это ускорит появление в поиске с недель до 1–2 дней.

## 🚀 Что поднимет позиции в поиске (SEO-тактика)

### 1. Backlinks — ссылки на твой сайт с других сайтов
Google считает ссылки «голосами». Чем больше качественных сайтов ссылаются на твой — тем выше ты в поиске.

Где бесплатно получить:
- **GitHub Profile** — добавь ссылку в bio: https://github.com/settings/profile
- **LinkedIn** — в разделе «About»: https://linkedin.com/in/
- **Telegram-каналы** по фрилансу/разработке — напиши пост
- **Reddit** — r/forhire, r/freelance
- **Хабр Карьера** — https://career.habr.com (создай профиль)
- **Upwork / Fiverr / Kwork** — в профиле
- **Комментарии на блогах** по разработке (с реальным комментарием, не спам)

### 2. Контент — добавь раздел «Блог» или «Кейсы»
Google любит сайты, которые регулярно обновляются. Напиши 3–5 статей:
- «Как я сделал Cursor-скиллы для безопасного рефакторинга»
- «5 трендовых дизайнов лендингов в 2026 году»
- «Как я настраиваю AI-агентов для клиентов»

Каждая статья = +1 страница в поиске, +ключевые слова, +время на сайте.

### 3. Локальное SEO (если работаешь с конкретным рынком)
Добавь себя в:
- **Google Business Profile** — https://business.google.com (если есть физический адрес)
- **Yandex Бизнес** — https://business.yandex.ru
- **2GIS** — https://2gis.ru (для России и СНГ)

### 4. Скорость сайта (уже хорошо)
Твой сайт весит 50KB JS / 3KB CSS (gzip) — это **очень быстро**. Google penalizes медленные сайты, у тебя тут всё отлично.

### 5. Мобильная адаптивность (уже хорошо)
Твой сайт адаптивный — Google проверяет это и повышает в mobile-first индексе.

## 📊 Как проверить, что сайт проиндексирован

Через 1–2 недели после всех шагов, введи в Google:
```
site:viacheslav.dev
```
Должны появиться все страницы твоего сайта.

В Yandex:
```
site:viacheslav.dev
```

Если ничего не появилось — подожди ещё неделю, потом запроси переобход в Search Console.

## ⚠️ Важно

- **Не жди быстрых результатов.** Google индексирует от 1 дня до 4 недель. Первые позиции — через 1–3 месяца.
- **Не используй «быстрые SEO-услуги»** за деньги — они часто делают хуже (спам-ссылки).
- **Пиши настоящий контент** — статьи, кейсы. Google любит уникальный, полезный текст.
- **Обновляй сайт** хотя бы раз в месяц — добавляй новые проекты в GitHub (они подтянутся автоматически) и пиши статьи.
